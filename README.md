# Анализ клиентской базы банка — Yandex DataLens

## О проекте

Учебный проект по анализу данных клиентов банка и визуализации результатов в интерактивном дашборде на платформе Yandex DataLens.

## Цель проекта

Представить ключевые характеристики клиентской базы, исследовать распределение клиентов по категориям платёжной дисциплины и визуализировать показатели переводов.

## Содержание дашборда

- Ключевой показатель доли клиентов с категорией BAD.
- Анализ количества переводов в зависимости от возраста и пола клиентов.
- Распределение клиентов по каналам привлечения.
- Сравнение категорий клиентов BAD, GOOD и MIDDLE по каналам привлечения.
- Анализ сумм переводов по типам переводов.
- Сводная таблица с разбивкой по регионам, каналам привлечения и категориям клиентов.
- Фильтры по оператору связи и региону.

## Инструменты

- Yandex DataLens
- Визуализация данных
- Исследовательский анализ данных

## Результат

Создан дашборд, объединяющий ключевые показатели, несколько видов визуализаций и фильтры для изучения характеристик клиентской базы.
